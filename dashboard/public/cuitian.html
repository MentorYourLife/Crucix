LINE BOT 設定指南
三步驟接通 LINE 推播
1

建立 LINE 開發者帳號 + 頻道

前往 developers.line.biz/console，用你的 LINE 帳號登入。
建立 Provider → 建立「Messaging API」頻道 → 隨便取個名字

2

取得金鑰並填入 .env

「Basic settings」→ 複製 Channel Secret
「Messaging API」→ Issue Channel access token (長期)
加你的官方帳號好友 → 在「Messaging API」掃 QR 碼取得 User ID
（或訊息第一條會有你的 ID）

LINE_CHANNEL_SECRET=你的Channel Secret
LINE_CHANNEL_ACCESS_TOKEN=你的Token
LINE_USER_ID=你的User ID
3

用 Cloudflare Tunnel 建立公開連結（免費）

Crucix 需要一個公開的 HTTPS 網址讓 LINE 確認 Webhook。
下載 cloudflared，放到 C:\Windows 下，然後執行：

cloudflared tunnel --url http://localhost:3117

複製輸出的 https://xxx.trycloudflare.com
填到 LINE Developer Console → Webhook URL：

https://xxx.trycloudflare.com/line/webhook

重啟 Crucix 伺服器，LINE Bot 就上線了！✓

可用指令
傳給你的 LINE Bot：
/status — 查看系統狀態
/brief — 當前情報摘要
/sweep — 立即觸發情報掃描
自動推播：緊急情報、油價突破、VIX飆高、AI策略建議
